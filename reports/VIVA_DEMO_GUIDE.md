    2. *Class 1:* Bio-filtration (requires organic / surfactant reduction)
    3. *Class 2:* Restricted Irrigation (safe for subsurface / landscaping)

### Frequently Asked Viva Questions & Answers

1. **Q: Why combine XGBoost with deterministic rules rather than relying on ML alone?**
   * *A:* Machine learning models optimize complex multi-dimensional patterns but cannot guarantee absolute zero risk in edge cases. Pure rule systems lack flexibility across continuous multivariate distributions. Our hybrid architecture combines the operational predictive power of XGBoost with a fail-safe deterministic safety layer that enforces EPA and WHO greywater quality standards.

2. **Q: Why does Isolation Forest anomaly detection not automatically force diversion to the sewer?**
   * *A:* Statistical anomalies simply indicate that a sample lies in a low-density region of the training manifold (e.g., unusual temperature or mineral conductivity). If all pathogen, chemical, and physical parameters are well within safe thresholds, dumping clean water to the sewer would cause wasteful operational inefficiency. It is instead marked for `ANOMALY_REVIEW`.

3. **Q: How does the system handle sensor or API failures?**
   * *A:* The pipeline features built-in graceful degradation:
     * If the Weather API fails $\rightarrow$ weather status is set to `UNAVAILABLE` and routing proceeds safely using conservative defaults.
     * If SHAP fails $\rightarrow$ explanation falls back to `SHAP_UNAVAILABLE` without interrupting the real-time routing decision.
     * If ML models are missing $\rightarrow$ explicit `MODEL_UNAVAILABLE` exceptions are raised rather than inventing fake predictions.
